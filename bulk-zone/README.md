# متجر Bulk Zone

متجر مكملات عربي مع لوحة إدارة للمنتجات والأقسام والعروض والكوبونات والدليل التثقيفي والأوردرات.

## التشغيل على Windows

1. ثبّت Node.js 20 أو أحدث.
2. لتشغيل المتجر مباشرة، افتح `open-store.bat`. للوحة الإدارة فقط افتح `open-dashboard.bat`، أو افتح `open-bulk-zone.bat` لتشغيل الاثنين في تبويبين. سيظهر نافذة تشغيل صغيرة للتطبيق، والمتصفح يفتح تلقائياً بعد جاهزية الموقع. في أول مرة سيطلب منك كلمة مرور لوحة الإدارة داخل نافذة التشغيل.
3. تظل نافذة تشغيل التطبيق مفتوحة أثناء استخدام المتجر؛ أغلقها لإيقافه.
4. من **إعدادات المتجر** أضف رقم واتساب الدولي وبيانات التواصل والشعار.

يمكن تشغيله يدوياً بعد الإعداد:

```powershell
npm install
npm start
```

## قاعدة البيانات

المتجر مربوط بالفعل بقاعدة **Turso Cloud** باسم `bulk-zone-store`. بيانات الاتصال محفوظة محلياً في `outputs/.env`، وهذا الملف مستثنى من Git ولا يُعرض للواجهة. عند تشغيل التطبيق ينشئ الجداول والبيانات الأولية في القاعدة السحابية تلقائياً.

إذا أردت تشغيل نسخة محلية بلا اتصال سحابي، يستخدم التطبيق SQLite ويحفظ البيانات في `data/bulk-zone.db`. ويمكن تغيير الاتصال السحابي لاحقاً من متغيري `TURSO_DATABASE_URL` و`TURSO_AUTH_TOKEN` في `.env`. لا تضع رمز الاتصال في ملفات الواجهة أو ترسله في المحادثة.

توثيق الاتصال الرسمي: [Turso TypeScript Quickstart](https://docs.turso.tech/sdk/ts/quickstart).

عند أول تشغيل على قاعدة جديدة يضيف المتجر بيانات تجريبية للأقسام والمنتجات والعروض وكود `FIRST10`. غيّر الأسعار والصور والمنتجات التجريبية من لوحة الإدارة قبل استقبال طلبات حقيقية.

## ما تحتويه لوحة الإدارة

- إضافة وتعديل وحذف الأقسام والمنتجات، إظهارها أو إخفاؤها، ورفع الصور أو إضافة رابط صورة.
- إعداد الأحجام والنكهات، السعر، الوصف، الفائدة وطريقة الاستخدام والتنبيهات.
- التحكم في شريط العروض المتحرك وأكواد الخصم (نسبة أو مبلغ ثابت، حد أدنى، وعدد استخدامات).
- متابعة الأوردرات وبيانات العملاء والمنتجات المطلوبة، وتغيير حالة الطلب.
- تعديل اسم المتجر ورقم واتساب والشعار، وإدارة مقالات دليل المكملات.
- إضافة المحافظات المتاحة وأسعار الشحن أو إيقافها من قسم الشحن والمحافظات. لا يُقبل الطلب دون اختيار محافظة مفعّلة.
- قص صور المنتجات ونِسَب الأحجام على مقاس بطاقة المنتج الظاهر في المتجر.

صورة الرفع تُحفظ داخل قاعدة البيانات لتبسيط تشغيل المتجر. للصور الكبيرة أو كتالوج كبير، استخدم روابط صور مضغوطة وخدمة تخزين ملفات مستقلة.

## ملاحظات مهمة

- المنتجات والأسعار والأكواد عند التثبيت بيانات توضيحية، وليست مخزوناً أو عروضاً فعلية.
- الدفع الإلكتروني والشحن الآلي غير مفعّلين؛ الطلبات تُسجّل في لوحة الإدارة للتواصل والتأكيد.
- معلومات المكملات عامة وليست وصفة أو نصيحة طبية. تعليمات الملصق ومراجعة الطبيب أو الصيدلي عند وجود حالة صحية أو أدوية لها الأولوية.
- لا تنشر المتجر على الإنترنت قبل تعيين كلمة مرور قوية، وضبط `DATABASE_URL` عند اختيار قاعدة سحابية، واختبار عملية استقبال الطلبات بنفسك.

## النشر على Vercel

المشروع يجهز واجهة المتجر في `public/` ويصدر تطبيق Express كـVercel Function. قبل نشر الإنتاج اضبط في مشروع Vercel متغيرات البيئة `TURSO_DATABASE_URL` و`TURSO_AUTH_TOKEN` و`ADMIN_PASSWORD` و`SESSION_SECRET`، ثم انشر باستخدام Vercel CLI. لا ترفع ملف `.env`؛ قواعد Vercel تستثنيه.
